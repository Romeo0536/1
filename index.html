สลับ/เพิ่มบริษัทได้ — แต่ละบริษัทเก็บเอกสารแยกกัน

☁️ ซิงค์ข้ามเครื่อง (มือถือ ↔ คอม)ยังไม่ตั้งค่า

ล็อกอิน Gmail เดียวกันทุกเครื่อง ข้อมูลซิงค์ผ่าน Google Drive ของคุณอัตโนมัติ

👤
ยังไม่ได้ล็อกอินข้อมูลเก็บในโฟลเดอร์ซ่อนของแอปใน Drive คุณ

วาง Client ID แล้วกดล็อกอิน — เครื่องอื่นล็อกอินอีเมลเดียวกันก็ซิงค์ทันที ไม่ต้องใส่รหัสอะไรเพิ่ม (ข้อมูลถูกเข้ารหัสอัตโนมัติก่อนขึ้น Drive)

📖 วิธีขอ Client ID (ฟรี ครั้งเดียว)
  1. เข้า console.cloud.google.com → สร้าง Project
  2. เมนู APIs & Services → Enable APIs → เปิด Google Drive API
  3. OAuth consent screen → User Type External → กรอกชื่อแอป/อีเมล → ในหน้า Test users เพิ่มอีเมล Gmail ของคุณ
  4. Credentials → Create Credentials → OAuth client ID → Application type Web
  5. ช่อง Authorized JavaScript origins ใส่ https://romeo0536.github.io
  6. คัดลอก Client ID (ลงท้าย .apps.googleusercontent.com) มาวางช่องบน → กดล็อกอิน

* จะมีจอ "Google hasn't verified this app" — กด Advanced → ไปต่อ ได้เลย (เป็นแอปส่วนตัวคุณ)
